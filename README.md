# ResumeFill

**上传简历，在招聘网站快速填写资料。**

ResumeFill 是一个由 **Python 本地资料编辑器**和 **Chrome / Edge 浏览器扩展**组成的简历填写工具。它可以从简历文件提取文字，整理并保存个人资料，再将资料填入网页表单，减少求职时反复输入相同信息的操作。

简历解析在本机完成，无需 API Key，不调用大模型或第三方简历解析服务。网页填写由用户主动触发，**不会自动提交申请**。

> 当前版本：2.1。通用字段匹配与规则解析仍有兼容边界，请在提交前核对内容。

### 2.1 上传与识别修复

文件选择栏不再自动清空；上传后显示文件名、读取字数和识别项数。新增“重新读取所选文件”和“粘贴简历文字识别”。补强多栏学校/专业/学历/日期、公司与职位、分节技能和经历的提取。合并模式会明确告知保留了哪些已有字段；识别较少或读取失败时会显示提示。

升级时先关闭旧版 Python 启动窗口，再运行新版，避免端口仍被旧服务占用。

## 功能

- **多格式导入**：支持文字 PDF、DOCX、TXT、Markdown、HTML、CSV，以及本工具导出的 JSON。
- **资料编辑**：核对并修改识别结果，补充学校、技能、工作经历和自定义字段。
- **填写前预览**：显示网页字段、原值、待填内容及跳过原因，支持逐项勾选。
- **快速填写**：根据中英文标签、字段名及 autocomplete 信息识别常见输入框。
- **多份简历**：扩展中最多保存 10 份资料，适合切换岗位或语言版本。
- **手动字段记忆**：为无法识别的输入框指定资料，下次可复用对应关系；不同简历版本独立保存。
- **已有内容保护**：默认保留网页已填写内容，需要替换时可主动开启覆盖。
- **撤销填写**：记录当前页面最多 500 次插件修改，尽量保留填写后手动修改的内容。
- **自动备份**：本地编辑器保存前备份上一版，最多保留 10 个有效备份，支持恢复。
- **防止编辑冲突**：通过版本标记拦截其他窗口保存后产生的过期修改。
- **安全合并导入**：可只补充空白字段，保留已经手动编辑的内容。
- **资料搜索与导出**：搜索字段、复制内容、下载草稿或导出当前简历 JSON。

## 快速开始

### 1. 获取项目

通过 GitHub 的 **Code → Download ZIP** 下载并解压，或使用 Git 克隆本仓库。

请将整个项目保存在固定目录中，不要直接在压缩包内运行。

### 2. 启动本地编辑器

需要 **Python 3.10 或更新版本**。Windows 安装 Python 时，请勾选 **Add Python to PATH**。

Windows 双击：

```text
start.bat
```

也可以在项目根目录运行：

```powershell
py -3 launcher.py
```

macOS / Linux：

```bash
python3 launcher.py
```

启动器会创建本地 `.venv` 环境，尝试安装 PDF 读取依赖，并自动打开：

```text
http://127.0.0.1:8765
```

首次安装 PDF 依赖需要网络。依赖安装失败时，仍可使用不依赖 pypdf 的 DOCX、TXT 等格式。

### 3. 导入并核对简历

1. 在本地编辑器上传简历。
2. 核对识别结果，补全需要的信息。
3. 点击 **保存并下载插件资料 JSON**。

默认导入方式为“只补充空白字段”。如果要换成一份全新简历，请取消该选项。

识别使用本地规则，无法保证适配所有简历排版。不要跳过人工核对。

### 4. 安装浏览器扩展

| 浏览器 | 扩展管理地址 |
|---|---|
| Chrome | `chrome://extensions` |
| Edge | `edge://extensions` |

打开对应页面后：

1. 开启 **开发者模式**。
2. 点击 **加载已解压的扩展程序**。
3. 选择项目中的 **extension** 文件夹，即包含 `manifest.json` 的目录。
4. 将 ResumeFill 固定到浏览器工具栏。
5. 打开扩展，导入刚才下载的资料 JSON。

### 5. 填写招聘网页

进入简历填写页面，打开扩展，点击 **扫描当前页 · 预览填写内容**，核对并勾选后点击 **确认填写勾选项**。

熟悉的表单也可使用 **直接填写常见字段**。默认不会覆盖已有内容。

**资料导入扩展后，日常填写无需运行 Python。** 只有重新解析或编辑资料时，才需要启动本地编辑器，并重新导出、导入 JSON。

## 使用技巧

### 无法识别的字段

在扩展中搜索并选择对应资料，点击 **选择网页输入框**，再点击网页目标输入框。工具会尝试填写并记住对应关系。

按 **Esc** 或点击 **取消选择模式**可取消。复杂控件无法直接操作时，可使用 **复制内容**后手动粘贴。

### 多段教育与工作经历

同一页出现多个学校、公司等重复字段时，工具会跳过自动填写，避免把同一段经历复制到多条记录。

可以添加“第二段实习公司”“第二段实习职责”等自定义字段，再手动指定对应输入框。需要新增经历行时，请先在网站自行点击“添加经历”。

### 多份简历

每次导入 JSON 默认新增一个版本，通过扩展顶部的下拉框切换。若要更新已有版本，导入前勾选 **更新当前版本**。

更新版本会重置该版本的字段记忆，避免自定义字段顺序变化后填错。其他版本的资料与记忆会保留。大型资料还受到浏览器本地存储总配额限制。

### 预览有效期

预览只保留在当前扩展弹窗中。关闭弹窗、切换资料或修改覆盖选项后，需要重新扫描。

填写前会重新检查网页地址、输入框特征、原值和下拉选项。发现变化时跳过相关项，避免直接使用过期预览。

### 备份与恢复

在本地编辑器的 **自动备份与恢复**区域选择历史版本即可恢复。恢复前会备份磁盘上的当前版；未保存的编辑内容请先通过 **仅下载当前草稿**保留。

## 文件格式

| 格式 | 说明 |
|---|---|
| PDF | 可复制文字的 PDF，需要 pypdf；有密码的文件请先解密 |
| DOCX | 支持正文及表格文字，无需安装 Microsoft Word |
| TXT / MD | 支持 UTF-8、带 BOM 的 UTF-16、GB18030 等常见编码 |
| HTML / HTM | 提取正文，忽略脚本与样式 |
| CSV | 适合“字段名,内容”形式 |
| JSON | 本工具导出的结构化资料 |
| DOC / RTF / 图片 / 扫描 PDF | 暂不支持，请先转换为 DOCX 或文字 PDF |

上传文件最大 **12 MB**，PDF 最多 **100 页**。单个资料字段最多 **30000 字**，自定义字段最多 **100 个**。资料内容超限时会报错，不会在保存时自动截断。

## 运行与开发

如果希望自行管理 Python 环境：

```bash
python -m venv .venv
```

激活虚拟环境后安装依赖并启动：

```bash
python -m pip install -r requirements.txt
python app.py
```

可选参数：

```bash
# 更换端口
python app.py --port 8766

# 启动时不自动打开浏览器
python app.py --no-browser
```

更换端口后，请使用终端显示的地址。扩展中的编辑器快捷链接固定指向默认 8765 端口。

## 项目结构

| 路径 | 用途 |
|---|---|
| `app.py` | 本地 HTTP 服务、资料保存、版本检查及备份恢复 |
| `parser.py` | 文件文字提取、规则解析与资料校验 |
| `launcher.py` | 虚拟环境准备、依赖安装及启动 |
| `start.bat` | Windows 双击启动入口 |
| `static/` | 资料编辑器与演示表单 |
| `extension/` | Manifest V3 浏览器扩展 |
| `examples/` | 虚构演示资料 |
| `tests/` | Python 与 JavaScript 回归测试 |
| `data/` | 运行后生成的当前资料及备份，已列入 `.gitignore` |
| `UPGRADE.md` | 从旧版升级的操作说明 |
| `TEST_REPORT.md` | 验证范围与未覆盖内容 |

Python 部分主要使用标准库，PDF 读取依赖 **pypdf**。扩展采用原生 JavaScript、HTML 和 CSS，无需前端构建步骤。

## 数据与隐私

- 简历解析在本机进行，不上传模型或第三方解析服务。
- Python 服务只监听 `127.0.0.1`。
- 当前资料位于 `data/profile.json`，历史版本位于 `data/backups/`。
- 浏览器资料保存在扩展本地存储中，未使用浏览器同步存储。
- 扩展使用 `activeTab` 按用户操作访问当前页面，没有常驻全站访问权限。
- 工具不会自动提交表单；主动填写网页后，相应内容仍可能被该网站脚本读取或保存。
- 本地资料、备份和导出的 JSON **未加密**，请妥善保管。

提交代码到 GitHub 前，请确认没有加入真实简历、导出的资料 JSON、个人信息或运行生成的 `data/` 内容。示例文件只包含虚构资料。

## 兼容范围与限制

支持普通 HTML 输入框、文本域、原生下拉框和部分可编辑区域，并尝试处理开放 Shadow DOM 及同源 iframe。

以下情况可能需要手动操作：

- 跨域 iframe、封闭 Shadow DOM、自定义下拉框和复杂日期控件。
- 特殊富文本、异步校验或会重置输入值的页面。
- 网站附件上传、新增经历行及多步骤页面切换。

浏览器设置页、扩展商店和 PDF 预览页不支持填写。扫描 PDF 暂无 OCR。

**当前没有完成真实 Chrome / Edge 扩展端到端验证，也没有覆盖各招聘网站的实际表单。PDF 读取分支因测试环境依赖安装受限，尚未完成实测。** 模拟测试通过不代表所有网站兼容，提交前仍需人工核对。

## 常见问题

**启动时找不到 Python**

安装 Python 3.10 或更新版，并添加到 PATH；也可在终端运行 `py -3 launcher.py` 查看错误。

**PDF 依赖安装失败**

检查网络后重试。也可以先使用 DOCX 或 TXT，再手动运行 `python -m pip install -r requirements.txt`。

**端口被占用**

关闭之前的启动窗口，或使用 `--port` 更换端口。

**修改资料后，扩展内容没有更新**

重新下载 JSON 并导入扩展。当前没有编辑器与扩展之间的自动同步。

**扫描结果为零或部分字段跳过**

确认当前版本有对应资料、网页字段可见且可编辑。查看预览中的跳过原因，必要时使用手动指定或复制内容。

**升级后不能填写**

重新加载扩展并刷新招聘页面，再扫描。详细步骤见 [UPGRADE.md](UPGRADE.md)。
